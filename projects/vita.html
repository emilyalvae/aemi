01 / OVERVIEW

Project Overview

Vita is an AI assistant created to provide contextual responses based on a controlled collection of documents. The system combines document retrieval, semantic search and an agent workflow to determine how each user request should be processed.

PROJECT TYPE
AI Assistant · RAG · Agents
02 / PROBLEM

The Problem

Traditional question-and-answer interfaces are limited when the information required to answer a request is contained inside a collection of private documents.

The objective was to create a system capable of retrieving relevant information and determining the appropriate action based on the user's request.

03 / SOLUTION

The Solution

The solution uses a Retrieval Augmented Generation pipeline combined with LangGraph to orchestrate different processing paths.

Relevant information is retrieved from the document knowledge base.

07 / CHALLENGES

Challenges

One of the main challenges was designing the retrieval pipeline so that the generated responses remained grounded in the available documentation.
